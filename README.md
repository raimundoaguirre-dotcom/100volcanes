# 100volcanes.org

Sitio estático de 100 Volcanes. Sin build: `index.html` + `img/`.

## Publicar en Cloudflare
- Conectar este repositorio en Cloudflare (Workers & Pages).
- Comando de build: ninguno. Carpeta de salida: `/` (raíz).
- Dominio personalizado: `100volcanes.org` y `www.100volcanes.org`.
